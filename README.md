# BL

手机优先的选择题练习网页，按 25 次考试分单元。纯静态网页，进度保存在本机浏览器，支持添加到主屏幕和离线使用。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 页面和样式 |
| `app.js` | 出题、判分、错题本等全部逻辑 |
| `data.js` | 题库（由 `build.py` 自动生成，不要手改） |
| `data/vocab.json` | 词汇表：每条 `page`（页码）、`en`、`zh` |
| `data/sentences.json` | AE/AV/AI 句子；`shared` 是三本共用的第 1–30 句 |
| `data/beisong.json` | 背诵N，`"1"` 对应第 1 次考试 |
| `data/weekly.json` | 周考题库：每次周考 5 张卷子（每天一张） |
| `sw.js`、`manifest.webmanifest`、图标 | 离线缓存和“添加到主屏幕” |

## 加新材料

1. 在 `data/` 里对应的 JSON 文件中添加内容（比如在 `beisong.json` 的 `sets` 里加 `"2": [...]`）。
2. 运行 `python build.py`，重新生成 `data.js`。
3. 重新上传到 GitHub（见下面第 3 步），手机上联网打开一次就会更新。

## 部署到 GitHub Pages

> 注意：GitHub Pages 免费版要求仓库公开，题库内容任何人都能看到。

1. 在 GitHub 新建仓库，比如叫 `english-practice`，选 Public。
2. 把这个文件夹里的所有文件上传到仓库（网页上点 “Add file → Upload files”，或用 GitHub Desktop）。
3. 仓库 Settings → Pages → Source 选 “Deploy from a branch”，分支选 `main`、目录选 `/ (root)`，保存。
4. 等一两分钟，网址是 `https://你的用户名.github.io/english-practice/`。
5. 手机浏览器打开这个网址：
   - iPhone（Safari）：点分享按钮 → “添加到主屏幕”
   - 安卓（Chrome）：点右上角菜单 → “添加到主屏幕”

第一次联网打开后，没网也能练。

## 月考和周考

首页顶部可以切换“月考”和“周考”。月考是原来按 25 次考试分的单元；周考每次 5 张卷子，模拟考试默认从本周卷子里抽 30 题。

加周考卷子：在 `data/weekly.json` 对应周的 `papers` 里填内容，然后运行 `python build.py`。

- `items`：卷子上的单词或句子，写 `{"en": "...", "zh": "..."}`，网站自动出英→中、中→英选择题。可加 `"kind": "word"` 或 `"sent"`，不写时 4 个词以上算句子。
- `questions`：卷子上的原题，写 `{"q": "题干", "options": ["A", "B", "C", "D"], "answer": 0, "explain": "解析（可不写）"}`，`answer` 是正确选项的序号（从 0 开始）。出题时选项顺序会打乱。
- 新的一次周考：在 `weeks` 里加一条，`id` 往上加 1，比如 `{"id": 2, "title": "第2次周考", "papers": [...]}`。首页最新的一次排最上面。

## 练习规则

- 每题 3 个选项（和正式考试一样三选一）。单词的干扰项优先选拼写相近的词，句子的干扰项优先选用词相近的句子。
- 答错的题本轮稍后会再出一次，并进入错题本；同一题连续答对 2 次算掌握，自动移出错题本。
- 第 7 次起可开关“混入整本词汇”，开启后本次新句子至少占六成，其余从整本词汇里优先出没掌握和常错的词。
- 第 16 次起增加“句子 中→英”。
- 背诵里原表“中文在左、英文在右”的句子（数据里 `zhFirst: true`，背诵7 起每份第 16–30 句），考试是给中文选英文，所以这些句子只出“句子 中→英”。
- 模拟考试：月考可选 20 / 50 / 100 题，周考默认 30 题。不限时，中途不显示对错，交卷后出分数、用时并列出错题，没答的算错。考错的题进错题本，分数存进“考试记录”。
- 收藏：做题或浏览内容时点 ☆ 收藏难题，首页“收藏”里可以单独练。
- 薄弱词优先：练习、混合复习、模拟考试都有这个开关。打开后按“错误率高、错得多、最近没连对”排序，最常错的先出；没练过的排中间，已掌握的排最后。
